# Training Program

A workout app with two programs (Men's Push Pull Legs, Women's glute-focused), animated exercise demos, a weekly schedule and a guided set and rest timer.

## Install on your phone (no computer needed)

**Android, app file:** open the [Releases page](../../releases) on your phone, tap **TrainingProgram.apk**, open the download, and allow installing from your browser when Android asks.

**iPhone or Android, from the browser:** open the website link from Settings → Pages, then:
- iPhone (Safari): Share → **Add to Home Screen**
- Android (Chrome): ⋮ menu → **Install app**

### Turning on the website (one time)

GitHub Pages is free for public repositories. Private repositories need a paid GitHub plan.

1. Settings → General → Danger Zone → **Change visibility** → Public (skip this on a paid plan).
2. Settings → **Pages** → Source: **GitHub Actions**.
3. Actions → **Publish website** → **Run workflow**. The link appears on the Pages settings page in about a minute.

### Turning on automatic Android builds (optional)

The **Build Android app** workflow builds a new APK on GitHub's servers every time the code changes. It needs the app's signing key, stored as two repository secrets (Settings → Secrets and variables → Actions → New repository secret):

- `ANDROID_KEYSTORE_BASE64`: the contents of `keystore-base64.txt`
- `ANDROID_KEYSTORE_PASSWORD`: the contents of `keystore-password.txt`

Keep those two files somewhere private, like a password manager. Android only installs updates signed with the same key, and the key must never be committed to this repository.

## Ways to install

There are two ways to install it on a phone:

| | Web app (PWA) | App store apps |
|---|---|---|
| Works on | iPhone and Android | iPhone and Android |
| Cost | Free | Google Play $25 once; Apple $99/year |
| Needs | Any free static web host | Android Studio (any computer); a Mac with Xcode for iPhone |
| Time to first install | About 5 minutes | An afternoon, plus store review |
| Updates | Re-upload the `app` folder | Rebuild and resubmit |

## Project layout

```
index.html            The app's source page (also published as the Claude artifact)
app/                  The built, installable web app. This is what gets hosted or bundled
  index.html          Generated by tools/build_app.py. Do not edit by hand
  manifest.webmanifest, sw.js, icons/, fonts/
tools/build_app.py    Rebuilds app/ from index.html
tools/make_icons.py   Draws the app icons
assets/               Source art for the native icons and splash screens
android/              Android Studio project (Capacitor)
ios/                  Xcode project (Capacitor)
capacitor.config.json App id and name for the native apps
```

After you change `index.html`, run `npm run build` to rebuild `app/`, or `npm run sync` to also copy it into the Android and iOS projects.

## Option 1: Install as a web app (recommended to start)

### 1. Put the `app` folder online

Any static host with HTTPS works. The easiest are:

- **Netlify Drop**: go to https://app.netlify.com/drop, sign in, and drag the `app` folder (or `training-program-web.zip`) onto the page. You get a link like `https://something.netlify.app`.
- **GitHub Pages**: create a repository, upload the contents of `app/`, then turn on Settings → Pages.
- **Cloudflare Pages**: create a project and upload the `app` folder.

### 2. Install it on the phone

**iPhone (Safari):** open the link, tap the **Share** button, then **Add to Home Screen**.

**Android (Chrome):** open the link, tap the **⋮** menu, then **Install app** (or **Add to Home screen**).

The app then opens full screen from its own icon, and works with no internet connection after the first launch.

## Option 2: Publish to Google Play and the App Store

First install Node.js 20 or newer, then in this folder run:

```bash
npm install
```

### Android

1. Install [Android Studio](https://developer.android.com/studio).
2. Run `npm run android`. This rebuilds the app and opens the project in Android Studio.
3. To try it on your phone, connect it with USB debugging on and press **Run**.
4. To publish, use **Build → Generate Signed App Bundle**, then upload the `.aab` file in the [Google Play Console](https://play.google.com/console).

### iPhone

You need a Mac with Xcode, plus an [Apple Developer account](https://developer.apple.com/programs/) to publish.

1. Run `npm run ios`. This rebuilds the app and opens the project in Xcode.
2. Under **Signing & Capabilities**, choose your team.
3. To try it, pick your iPhone as the target and press **Run**.
4. To publish, use **Product → Archive**, then upload the build to App Store Connect.

### Before you submit

- **App id:** change `appId` in `capacitor.config.json` (currently `app.trainingprogram.mobile`) to one you own, such as `com.yourname.training`, before your first store upload. You cannot change it after.
- **Store listing:** you need `app/icons/icon-1024.png` for the icon, a few screenshots, a short description, and a privacy policy link. The app collects no data. Checkmarks and settings stay on the phone.
- **Apple review:** Apple sometimes rejects apps that are "just a website". This app works fully offline with its own animations and timer, which helps. Adding a native feature, such as workout reminders with `@capacitor/local-notifications`, makes approval more likely.
